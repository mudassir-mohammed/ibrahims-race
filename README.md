# Ibrahim's Race

A keyboard-controlled racing game built for kids.

## How to play

- **← →** arrow keys to switch lanes
- **Spacebar** to honk the horn
- **P** or **Esc** to pause
- **M** to mute

Grab ⭐ stars (10 pts) and 🪙 coins (3 pts). Dodge 🚧 cones and oil slicks!

## Live

[Play it here](https://mudassir-mohammed.github.io/ibrahims-race/)

## Features

- 6 cars to choose from (Ferrari, Lamborghini, Bugatti, McLaren, Porsche, Tesla)
- 4 tracks (Sunny Day, Sunset, Night City, Forest)
- Voice praise (works best in Chrome / Safari)
- Mobile-friendly (swipe / tap left-right side)
- Saves high score locally
- Fully self-contained, works offline after first load
